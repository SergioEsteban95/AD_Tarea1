# 📂 Tarea 1 - Acceso a Datos (Persistencia en Ficheros)

Proyecto desarrollado para el módulo de **Acceso a Datos** del Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

## 🚀 Contenido de la Práctica

El proyecto implementa la gestión de ficheros y directorios en Java a través de cuatro ejercicios prácticos:

- **Ejercicio 1:** Creación de directorios y archivos de texto utilizando la clase `File` y manejo de excepciones de E/S (`IOException`).
- **Ejercicio 2:** Implementación de un menú interactivo por consola con bucles y validaciones para crear y eliminar ficheros y directorios específicos.
- **Ejercicio 3:** Operaciones avanzadas que incluyen el borrado recursivo de directorios con contenido y la escritura estructurada de datos (listado de provincias de Andalucía) usando `BufferedWriter`.
- **Ejercicio 4:** Práctica y comparativa de flujos de lectura y escritura de caracteres mediante flujos básicos (`FileWriter` / `FileReader`) y flujos con búferes (`BufferedWriter` / `BufferedReader`).

## 🛠️ Tecnologías y Herramientas Utilizadas
- **Lenguaje:** Java (JDK 17+)
- **Gestión de dependencias:** Maven (`pom.xml`)
- **Entorno de desarrollo:** IntelliJ IDEA
- **Control de versiones:** Git / GitHub
